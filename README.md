# MY GEDA.academy — Version 1 (maquette)

Cette première version est un **prototype frontend** adapté aux écrans de téléphone.
Il présente l'académie et un catalogue filtrable de cours, avec des fenêtres de programme.

## Ouvrir et modifier depuis Android

### Option la plus simple : GitHub dans le navigateur
1. Télécharge et décompresse `MY_GEDA_academy_v1.zip` sur ton appareil (ou garde les fichiers dans un dossier accessible).
2. Crée un compte sur https://github.com si nécessaire.
3. Dans GitHub, crée un nouveau dépôt, par exemple `my-geda-academy`.
4. Utilise l'option **Add file → Upload files** pour envoyer `index.html`, `styles.css`, `app.js` et ce README.
5. Pour modifier un fichier, ouvre-le sur GitHub et utilise le crayon **Edit**. Enregistre avec **Commit changes**.
6. Pour publier cette maquette gratuitement, active GitHub Pages dans **Settings → Pages**, choisis la branche principale et le dossier `/ (root)`. Attends la publication et ouvre l'URL fournie.
7. Teste le site sur téléphone, notamment les boutons et l'affichage mobile.

Les noms des menus peuvent évoluer selon la version mobile du site GitHub. Tu peux aussi utiliser un éditeur de code Android de confiance pour travailler localement.

## Fichiers
- `index.html` : structure des pages.
- `styles.css` : style responsive.
- `app.js` : catalogue et interactions de démonstration.

## Limites importantes de la V1
- Pas de vrais comptes utilisateurs.
- Pas de paiement, abonnement ou accès premium sécurisé.
- Les cours sont des exemples de programme, pas encore les contenus complets.
- Ne collecte pas de mots de passe ni de données de paiement avec cette maquette.

## Étape suivante
Ajouter un backend sécurisé (par exemple Supabase Auth + base de données), des espaces élèves, une gestion de rôles et des cours stockés en privé. Ensuite, choisir un prestataire de paiement qui accepte les marchands de RDC et confirmer les paiements **côté serveur** avant d'accorder l'accès.
